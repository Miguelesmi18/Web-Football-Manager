# ⚽ Web Football Manager

Plataforma web interactiva para la gestión de equipos, jugadoras, cuerpo técnico, plantilla, resultados de partidos y tabla de clasificación. 

Este proyecto fue desarrollado como parte del módulo de **Lenguajes de Marcas y Sistemas de Gestión de Información (DAW)** para demostrar habilidades en maquetación web, maquetación responsiva y organización de datos.

---

## 🚀 Funcionalidades Principales

* **📋 Formulario de Alta:** Registro e incorporación de nuevas jugadoras y entrenadores a la base del club.
* **👥 Gestión de Plantilla:** Visualización clara de los equipos con sus respectivas jugadoras e información del entrenador/a a cargo.
* **🏟️ Resultados de Partidos:** Registro histórico y detalle de los encuentros disputados (escudo del equipo rival, minutos jugados, goles anotados, tiempo y detalles del partido).
* **🏆 Tabla de Clasificación:** Tabla dinámica de posiciones ordenada por mayor puntaje en la liga.
* **🧩 Navegación Fluida:** Header interactivo con enlaces directos a las diferentes secciones y un Footer estructurado.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica base para el maquetado principal del sitio.
* **CSS3:** Maquetación responsiva, estilos visuales y adaptabilidad.
* **JavaScript (Vanilla):** Generación y manipulación dinámica del DOM mediante bloques `div` para renderizar las plantillas, la clasificación y los resultados.
* **JSON:** Estructura de datos para almacenar la información de los equipos, jugadoras y partidos.
